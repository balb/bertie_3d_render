
Run 3d_V3 and type in any of these .obj files or any more you find.

Then scale accordingly:

```
Cow: 1
Beetle: 10
Silly: 5
Suzanne: 5
Teapot: 1 or 2
Torus: 5
```

Controls:
W - forwards
S - backwards
A - strafe left
D - strafe right
Q - rise
E - descend
Arrow keys to look around.

If you cannot see anything, walk backwards as you often spawn inside a model.
